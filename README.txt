CyberShield Academy Version 5

Open this folder in VS Code. Open index.html using Live Server, or open index.html directly in Chrome.

This is a multi-page offline-capable learning prototype. Progress and display name use browser localStorage. There is no real authentication or cross-device sync. For production, connect a secure auth/database service.

Lessons are original and inspired by standard networking/cybersecurity practice, including the three Cisco lab documents provided as reference. Cisco Packet Tracer and other software are separate installations.

Only scan or capture systems and networks you own or have authorization to test.
